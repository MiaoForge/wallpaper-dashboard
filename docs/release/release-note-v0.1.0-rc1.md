## Highlights

- Wallpaper Dashboard includes a desktop monitoring panel, a tray collector,
  and a settings window for startup, weather, and pinned apps and games.
- The settings window uses a gray frosted-glass theme. Its collection page
  shows live CPU, GPU, memory, disk, fan, and peripheral data and keeps the
  cards visible while the collector is disconnected.
- Weather forecasts and air quality update independently, so available air
  quality data can still be shown during a forecast outage.

## Run on Windows

Extract the Windows x64 ZIP and start `wallpaper-dashboard.exe`. The settings
window and desktop panel require Microsoft Edge WebView2 Runtime. Start the
collector as administrator for supported Ryzen SDK temperature and MSI Center
fan readings.
